SWE artifacts from the networking domain

REST API — RESTCONF on IOS XE ✓ Live
Python requests library authenticating to JLM-LAB-R1 via RESTCONF. Five GET queries executed against the live router:

1. Hostname · 2. IOS version · 3. Full interface table (JSON parsed with VLAN + IP details) · 4. OSPFv2 process 1 (all 9 configured networks readable via API) · 5. NTP servers and master stratum (the NTP hierarchy, machine-readable)

Concepts demonstrated: HTTP GET method, YANG model paths, JSON parsing, programmatic device access. Bridges the Networking and SWE modules — same device, different lens. Full annotated code and output in the CCNA module (Domain 6).

Ansible + Netmiko — network automation ✓ Live
Ansible project built in full: inventory, vault.yml, playbook, cfg, cisco.ios collection. Playbook blocked at runtime by a 3-layer SSH KEX incompatibility — IOS XE 16.10 legacy SHA-1 KEX, network_cli ignoring all ssh_args overrides (cisco.ios bug #1133), ansible-pylibssh crashing on Apple Silicon ARM.

Solution: Netmiko, which configures paramiko directly at the Python level and bypasses all three layers. Backup script connects to C1111, runs show running-config, saves timestamped output to backups/. The failure documented more real-world automation knowledge than a clean playbook run would have. Full annotated code in the CCNA module (Domain 6).
