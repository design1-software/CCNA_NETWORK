Top 5 actions to close the gaps

1. Configure OSPFv2 on C1111 — this is the #1 gap
OSPF is the heaviest topic in Domain 3 (25% of exam). Your lab has static routes but zero dynamic routing. Add a loopback interface on C1111, configure OSPF process 1, advertise your VLAN subnets. When 3560CX goes live as L3 core, run OSPF between them. This single task closes your biggest weakness.
High priority C1111 supports it natively
2. Add IPv6 to at least 2 VLAN interfaces
IPv6 is expanded in v1.1. Configure dual-stack on VLAN 10 and VLAN 20 SVIs on C1111. Run show ipv6 interface brief. Takes 30 minutes and closes a real exam gap that most home lab people skip.
Medium priority C1111 IOS XE supports dual-stack
3. Pull Ansible forward — don't wait for Phase 7
Automation is 10% of the exam and the fastest-growing section. Write one playbook that backs up your C1111 running config using the cisco.ios.ios_config module. You already have Python skills and Docker. Ansible is a one-afternoon setup, and it feeds Phase 7 directly.
High priority Pulls Phase 7 forward
4. Enable RESTCONF on C1111 and make one Python API call
IOS XE supports RESTCONF natively. Enable it (restconf, ip http secure-server), then use Python requests to GET your interface list as JSON. This one task teaches REST API, HTTP methods, JSON parsing, and IOS XE programmability simultaneously — all v1.1 exam topics. One afternoon.
High priority New v1.1 content
5. Configure DHCP snooping + DAI on IoT VLANs
Layer 2 security features are in the v1.1 security domain. DHCP snooping and Dynamic ARP Inspection make real security sense on your IoT VLANs anyway. Configure them on VLAN 30 and 31 — they protect against rogue DHCP servers and ARP spoofing from compromised IoT devices.
Medium priority Fits existing security model
